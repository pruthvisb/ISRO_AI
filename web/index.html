The Scientific Discovery Pipeline

How raw stellar data is ingested, cleaned, analyzed, and classified by the Google Antigravity AI engine.

1. Data Acquisition

Ingests full-cadence TESS light curves from the MAST Archive, querying the TESS Input Catalog (TIC) to compile target fluxes.

2. Preprocessing

Performs sigma-clipping outlier removal and applies a rolling Savitzky-Golay filter to isolate and flatten stellar variability.

3. Transit Detection

Runs a Box Least Squares (BLS) periodogram search, identifying orbital periods, transiting durations, depths, and SNR.

4. Feature Engineering

Extracts statistical moments (skewness, kurtosis), odd-even depth differences, and folds light curves into fixed 200-bin vectors.

5. Ensemble Inference

Feeds tabular parameters into RF, XGBoost, and LightGBM models, while deep CNN-LSTM hybrids process the folded 1D profiles.

Machine Learning Architecture

Deploying a diverse ensemble of models designed for both tabular metadata and sequence-based phase profiles.

Tabular

Random Forest

Constructs an ensemble of decision trees over features like skewness, kurtosis, and out-of-transit noise level, providing high interpretability and feature importance rankings.

Tabular

XGBoost

Uses gradient-boosted trees to handle complex non-linear feature relationships, excelling at separating eclipsing binaries from deep planet candidates.

Tabular

LightGBM

Leaf-wise tree growth enables extremely fast training and predictions, acting as the speed-focused vetting classifier in the tabular ensemble.

Deep Learning

1D CNN

Ingests the binned, phase-folded light curve phase vector. Convolutional layers act as spatial shape matchers to identify U-shaped transits and V-shaped eclipses directly.

Deep Learning

CNN-LSTM Hybrid

Pairs feature-extracting 1D CNNs with a Long Short-Term Memory (LSTM) layer to capture sequential dependencies in phase space, excelling on low SNR signals.
